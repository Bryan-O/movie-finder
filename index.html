One quick bit of setup

StreamScout runs on the free TMDB movie database. Paste a TMDB API key and you're in. It stays in this browser.

  1. Make a free account at themoviedb.org.
  2. Head to Settings → API and ask for a key (pick "Developer").
  3. Copy the API Key or the API Read Access Token and paste it here.

Film and TV data from TMDB. Where-to-watch info from JustWatch. This product uses the TMDB API but is not endorsed or certified by TMDB.
