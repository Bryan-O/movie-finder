One-time setup

StreamScout uses the free TMDB movie database. Paste a TMDB API key to get started. It's stored only in this browser.

  1. Create a free account at themoviedb.org.
  2. Go to Settings → API and request a key (choose "Developer", personal use).
  3. Copy either the API Key or the API Read Access Token and paste it below.
